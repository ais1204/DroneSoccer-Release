# ルールブック Class 20・JDSF ルール

このゲームの、Class 20 を JDSF ルールで遊ぶときのルールです。v0.8.0 の内容で、CPU との試合も、人との対戦も同じルールです。ほかのクラスとルールは [ルールブックの一覧](../RULEBOOK.md) にあります。

日本ドローンサッカー連盟の [JDSF Referee Rule Book Vol.10(2026年7月1日改訂)](https://japan-dronesoccer.com/rule/JDSF%20Referee%20Rule%20Book%20Vol.10.pdf)の、「フィールド規定 Ⅲ class20 ①」と「競技規則 Ⅲ class20」をもとにしています。見出しの「JDSF」は、その規則の見出しです。公式と違うところは [公式ルールとの違い](#公式ルールとの違い) にまとめました。

## ルールの要点

- 5対5で戦います。1人が1機を操縦します。
- 得点できるのはストライカーだけで、1チームに2人います。相手のリングを正面からくぐると1点です。
- 得点したら、チームの全機が同時にハーフラインの自陣側にそろうまで、チームの誰も次の得点はできません。これをオフサイドといいます。
- 1セット3分で、先に2セット取ったチームの勝ちです。取ったセットの数が同じなら、全セットの総得点で決めます。
- 反則をするとペナルティが付きます。ペナルティキックはなく、ペナルティ1回を0.8点として、セットの終わりに相手の得点へ加えます。
- フライングをすると、その場で相手に1点が入ります。

## コートと機体

(JDSF フィールド規定 Ⅲ、ドローンボール Class20)

Class 40 の半分ほどの大きさのコートで、小さい機体を使います。

| 項目 | 大きさ |
|---|---|
| コート | 幅4m、長さ8m、高さ3m |
| 操縦エリア | 両方の短辺の外に幅2m |
| ハーフライン | 長辺の真ん中 |
| 離陸ライン | 短辺から1.5m内側 |
| リング | 外径50cm、穴の内径30cm、厚さ10cm |
| リングの位置 | 短辺から1.5m内側、中心の高さ2m、コートの中央を向く |
| 機体 | 直径20cmの球形、110g |

離陸ラインとリングの位置は、規定の1〜1.5mのうち FIDA と同じ1.5mにしました。リングの中心の高さは、規定の1.8〜2.2mの真ん中です。穴と機体のすき間は片側5cmで、Class 40 の半分です。

国内独自の class20 ②(幅3m、長さ6m)のコートはありません。

このルールブックでは、次の言葉を使います。

- **正面と裏:** リングのコートの中央を向いた側が正面、壁を向いた側が裏です。
- **自陣と相手陣:** ハーフラインで分けた、自分のリングがある側が自陣、相手のリングがある側が相手陣です。

機体どうしの体当たりは反則になりません。ぶつかると機体の向きが変わります。機体が軽いので、Class 40 より大きく向きが変わります。壁、床、天井に当たっても墜落しません。

## チームと役割

(JDSF 選手とチーム)

機体の輪の LED がチームの色(青か赤)で、機首の LED が役割の色です。ストライカーにはタグが付きます。

JDSF の編成は、ストライカー2人と、ゴールの守備やストライカーの手助けをするフィールドプレイヤー3人です。このゲームでは、フィールドプレイヤーの3人にリベロ、スイーパー、キーパーの動き方を割り当てています。

| 席 | 役割 | LED | 仕事 |
|---|---|---|---|
| 1番 | ストライカー | 緑 | 得点する |
| 2番 | ストライカー | 緑 | 得点する |
| 3番 | リベロ | 水色 | 前の守備。相手のストライカーに当たる |
| 4番 | スイーパー | 黄 | 後ろの守備。相手のストライカーがゴールへ近づくコースをふさぐ |
| 5番 | キーパー | 白 | リングの前で相手のストライカーを止める |

人が座っていない席は CPU が動かします。CPU のストライカーは、1人がリングへ向かい、もう1人はリングの前の守備に当たって道を空けるか、横で待ちます。前の1人が弾かれると、待っていたほうがくぐります。CPU の守備は、相手のストライカーが2人来ると、スイーパーとキーパーがリングに近いほうを、リベロが遠いほうを受け持ちます。

### 編成を変えるとき

上の表が規定の編成です。監督の画面では、席ごとに役割を変えられます。

- ストライカーは1チーム2人までです。
- ストライカーを1人にしたり、置かなかったりもできます。置かないチームはセットで得点できません。
- ほかの役割は、何人置いても、1人も置かなくても構いません。ガイドも置けますが、ガイドのタグは付きません。

## 試合の流れ

(JDSF 競技時間、競技の進行方法)

1試合は3分のセットを3回行います。1セットは次の順に進みます。

1. 全機が離陸ラインに並びます。キーパーがリングの真下で、ストライカーは両端です。
2. 長い笛が鳴り、画面に「用意」と出ます。
3. 3〜10秒後に短い笛が鳴り、画面に「開始」と出ます。いつ鳴るかは毎回変わり、残り時間も表示されません。
4. 3分間プレーします。
5. 終了の笛が鳴り、全機が着地します。
6. ペナルティがあれば、[得点に換算](#ペナルティの得点換算)して相手の得点に加えます。
7. セットの勝敗が決まります。

勝負が決まっていなければ、15秒の修理の時間のあとに次のセットを始めます。

## フライング

(JDSF ペナルティの適用 1、ペナルティの得点換算措置)

「用意」から「開始」までの間に、機体が離陸地点から15cmより離れるとフライングです。

- その場で相手チームに1点が入ります。点はそのセットの得点です。
- 機体は離陸地点へ戻されます。
- 1回の「用意」につき、1チーム1点までです。
- 警告は付きません。
- CPU はフライングをしません。

## 得点

(JDSF ポイントの獲得)

ストライカーの機体全体が、相手のリングを正面から裏へ抜けると1点です。2人のストライカーのどちらでも得点できます。

| 起きたこと | 結果 |
|---|---|
| ストライカーが正面から裏へ抜けた | 1点。オフサイドになる |
| ストライカーが途中まで入って戻った | 得点なし |
| ストライカーが裏から正面へ抜けた | 得点なし。オフサイドにはならない |
| オフサイド中に、どちらかのストライカーが正面から裏へ抜けた | 得点は無効。ペナルティ1回 |
| ストライカー以外が相手のリングをくぐった | 何も起きない |

## オフサイド

(JDSF 連続ポイント制限)

得点したチームはオフサイドになります。オフサイドの間は、もう1人のストライカーも得点できません。

**解除の条件:** チームの全機が同時に、機体全体でハーフラインを越えて自陣にいると解除されます。

- 得点した瞬間に自陣にいた機体も、そのまま自陣にいる必要があります。
- 戻った機体がまた相手陣へ出ると、その機体がもう一度戻るまで解除されません。
- 相手の機体が自陣へ戻るのを、わざと邪魔しても構いません。
- オフサイドの間は、そのチームが攻めるリングの LED が赤になります。解除すると白へ戻ります。
- オフサイドは、次のセットへ持ち越しません。

CPU は、自分のチームがオフサイドの間はハーフラインを越えません。

## 自分のリング

(JDSF ペナルティの適用 3)

守備では、自分のリングを正面から裏へ抜けても構いません。ただし、穴を通って正面へ戻ることはできません。リングの外を回って戻ります。

次の2つは反則で、ペナルティ1回です。ストライカーを含むすべての役割に当てはまります。

- 裏から穴へ少しでも入る。
- 正面から機体の半分以上入って、正面へ戻る。

機体の半分以上が自分のリングへ入ると、画面の左下に「裏へ抜けて」と出ます。そのまま裏へ抜ければ反則になりません。

## ペナルティ

(JDSF ペナルティの適用)

ペナルティが付くのは次の2つです。フライングはペナルティではなく、その場で1点になります。

- オフサイド中の得点
- 自分のリングへの逆侵入

ペナルティはセットごとに数え、次のセットへは持ち越しません。

## ペナルティの得点換算

(JDSF ペナルティの得点換算措置)

ペナルティキックは行いません。セットが終わると、ペナルティ1回を0.8点として、相手チームの得点に加えます。合計の点は小数点以下を四捨五入します。

| ペナルティの回数 | 相手に入る点 |
|---|---|
| 1回 | 0.8点なので1点 |
| 2回 | 1.6点なので2点 |
| 3回 | 2.4点なので2点 |
| 4回 | 3.2点なので3点 |
| 5回 | 4.0点なので4点 |

- 両チームのペナルティは相殺しません。両チームの分を、それぞれ相手に加えます。
- 加えた点で、セットの勝敗が変わることがあります。
- 得点板の左右に、そのチームのペナルティの数と、相手に入る点が出ます。
- セットの終わりに「ペナルティを得点に換算」と知らせ、数秒あとにセットの勝敗を知らせます。

## 勝敗

(JDSF 勝敗、引き分け)

**セット:** 得点の多いチームがセットを取ります。同点なら、そのセットは引き分けです。換算した点も得点に入ります。

**試合:** 先に2セット取ったチームの勝ちです。3セットが終わったら、取ったセットの多いチームの勝ちです。1勝2分でも勝ちになります。

**同点のとき:** 3セットで取ったセットの数が同じなら、全セットの総得点が多いチームの勝ちです。総得点も同じなら、試合は引き分けです。延長セットと PK 戦はありません。結果の画面に、総得点も出ます。

## 審判の合図

(JDSF 付則 主審・副審の信号)

判定はゲームが自動で行います。コートの横に主審が1人、それぞれのリングの近くに副審が1人ずつ立ち、判定を合図で見せます。画質を軽いにすると、審判の人は出ません。

| 人 | 動き | 意味 |
|---|---|---|
| 主審 | 両腕を横へ広げる | 用意、終了 |
| 主審 | 両腕を前へ伸ばす | 開始 |
| 主審 | 黄色の札を掲げる | フライング。相手に1点 |
| 副審 | 旗をまっすぐ上げる | 得点を認める |
| 副審 | 旗を頭の上で振る | 得点を認めない |
| 副審 | 旗を前へ伸ばしたままにする | オフサイド中。自陣へ戻る |
| 副審 | 旗を斜め下へ下ろす | 全機が戻った。オフサイド解除 |
| 副審 | チームの色の表示板を掲げる | そのチームのペナルティ |

反則とフライングでは、短い笛が1回鳴ります。オフサイド中の得点は、旗を振る合図だけで示します。

## 別の PC と遊ぶときに接続が切れたら

接続が切れた人の席は CPU が引き継ぎます。試合が終わるまでは、同じ席へ戻れます。部屋を作った人の接続が切れると、試合は続けられません。

## 公式ルールとの違い

| 項目 | JDSF の規則 | このゲーム |
|---|---|---|
| 役割 | ストライカー2人、フィールドプレイヤー3人 | 規定は同じで、フィールドプレイヤーをリベロ、スイーパー、キーパーにする。監督の画面で変えられ、ストライカーは2人まで |
| 機首の LED | チームの色だけ | 役割の色も光る |
| 総得点も同じとき | 決まりがない | 引き分け |
| 修理の時間 | セットの間に5分 | 15秒 |
| 操縦スペースの選択 | コイントスで決める | チームの色で決まっている |
| 墜落とリタイヤ | 操縦できなくなった機体はリタイヤして、オフサイドを解除できる | 機体が墜落しないので、リタイヤもない |
| 警告 | 3回で競技敗、同じ理由で2回ならセット敗 | 警告がない |
| セット敗、競技敗 | 重い違反に適用する | ない |
| 審判 | 主審、副審、映像の確認 | ゲームが自動で判定する。審判の人は合図を見せるだけ |
| フライングの合図 | 決まった形はない | 主審が黄色の札を掲げる |
| 機体の型 | SKYKICK 2 か SKYKICK EVO | Class 40 の機体の形をそのまま小さくしたもの |

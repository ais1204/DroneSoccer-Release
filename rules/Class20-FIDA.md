# ルールブック Class 20・FIDA ルール

このゲームの、Class 20 を FIDA ルールで遊ぶときのルールです。v0.8.0 の内容で、CPU との試合も、人との対戦も同じルールです。ほかのクラスとルールは [ルールブックの一覧](../RULEBOOK.md) にあります。

実際の競技の [FIDA Class 20 ルールブック 第5版(2025年10月)](https://www.dronesoccer.org/static/files/Rule-book-2.pdf)をもとにしています。見出しの「公式」は、その章と項の番号です。公式と違うところは [公式ルールとの違い](#公式ルールとの違い) にまとめました。

## ルールの要点

- 5対5で戦います。1人が1機を操縦します。
- 得点できるのはストライカーだけで、1チームに2人います。相手のリングを正面からくぐると1点です。
- どちらかのストライカーがリングをくぐったら、そのとき相手陣にいた味方が全員自陣へ戻るまで、チームの誰も次の得点はできません。これをオフサイドといいます。
- 1セット3分で、先に2セット取ったチームの勝ちです。
- 反則をするとペナルティが付き、セットのあとで相手にペナルティキックが与えられます。
- フライングは警告です。警告2回でペナルティ1回になります。

## コートと機体

(公式 第1章、第2章)

Class 40 の半分ほどの大きさのコートで、小さい機体を使います。

| 項目 | 大きさ |
|---|---|
| コート | 幅4m、長さ8m、高さ3m |
| 操縦エリア | 両方の短辺の外に幅2m |
| ハーフライン | 長辺の真ん中 |
| 離陸ライン | 短辺から1.5m内側 |
| リング | 外径50cm、穴の内径30cm、厚さ10cm |
| リングの位置 | 短辺から1.5m内側、中心の高さ2m、コートの中央を向く |
| 機体 | 直径20cmの球形、110g |

穴と機体のすき間は片側5cmで、Class 40 の半分です。リングの中心の高さは、規定の1.8〜2.2mの真ん中にしました。

このルールブックでは、次の言葉を使います。

- **正面と裏:** リングのコートの中央を向いた側が正面、壁を向いた側が裏です。
- **自陣と相手陣:** ハーフラインで分けた、自分のリングがある側が自陣、相手のリングがある側が相手陣です。

機体どうしの体当たりは反則になりません。ぶつかると機体の向きが変わります。機体が軽いので、Class 40 より大きく向きが変わります。壁、床、天井に当たっても墜落しません。

## チームと役割

(公式 2-❹、第3章)

機体の輪の LED がチームの色(青か赤)で、機首の LED が役割の色です。ストライカーにはタグが付きます。

公式の編成は、ストライカー2人と、ストライカーを守るディフェンダー3人です。このゲームでは、ディフェンダーの3人にリベロ、スイーパー、キーパーの動き方を割り当てています。

| 席 | 役割 | LED | 仕事 |
|---|---|---|---|
| 1番 | ストライカー | 緑 | 得点する |
| 2番 | ストライカー | 緑 | 得点する |
| 3番 | リベロ | 水色 | 前の守備。相手のストライカーに当たる |
| 4番 | スイーパー | 黄 | 後ろの守備。相手のストライカーがゴールへ近づくコースをふさぐ |
| 5番 | キーパー | 白 | リングの前で相手のストライカーを止める |

人が座っていない席は CPU が動かします。CPU のストライカーは、1人がリングへ向かい、もう1人はリングの前の守備に当たって道を空けるか、横で待ちます。前の1人が弾かれると、待っていたほうがくぐります。CPU の守備は、相手のストライカーが2人来ると、スイーパーとキーパーがリングに近いほうを、リベロが遠いほうを受け持ちます。

### 編成を変えるとき

上の表が規定の編成です。監督の画面では、席ごとに役割を変えられます。

- ストライカーは1チーム2人までです。
- ストライカーを1人にしたり、置かなかったりもできます。置かないチームはセットで得点できません。
- ほかの役割は、何人置いても、1人も置かなくても構いません。ガイドも置けますが、ガイドのタグは付きません。

## 試合の流れ

(公式 第7章)

1試合は3分のセットを3回行います。1セットは次の順に進みます。

1. 全機が離陸ラインに並びます。キーパーがリングの真下で、ストライカーは両端です。
2. 長い笛が鳴り、画面に「用意」と出ます。
3. 3〜10秒後に短い笛が鳴り、画面に「開始」と出ます。いつ鳴るかは毎回変わり、残り時間も表示されません。
4. 3分間プレーします。
5. 終了の笛が鳴り、全機が着地します。
6. ペナルティの回数に差があれば、[ペナルティキック](#ペナルティキック)を行います。
7. セットの勝敗が決まります。

勝負が決まっていなければ、15秒の修理の時間のあとに次のセットを始めます。

## フライング

(公式 7-❸、11-❷ⓓ)

「用意」から「開始」までの間に、機体が離陸地点から15cmより離れるとフライングです。

- そのチームに警告が1回付き、機体は離陸地点へ戻されます。
- 警告は、1回の「用意」につき1チーム1回までです。
- CPU はフライングをしません。
- ペナルティキックとシュートアウトでは、機体は戻されますが、警告は付きません。

## 得点

(公式 8-❶)

ストライカーの機体全体が、相手のリングを正面から裏へ抜けると1点です。2人のストライカーのどちらでも得点できます。

| 起きたこと | 結果 |
|---|---|
| ストライカーが正面から裏へ抜けた | 1点。オフサイドになる |
| ストライカーが途中まで入って戻った | 得点なし |
| ストライカーが裏から正面へ抜けた | 得点なし。オフサイドになる |
| オフサイド中に、どちらかのストライカーが正面から裏へ抜けた | 得点は無効。ペナルティ1回 |
| ストライカー以外が相手のリングをくぐった | 何も起きない |

## オフサイド

(公式 8-❷)

どちらかのストライカーが相手のリングをどちらの向きでも通り抜けると、そのチームはオフサイドになります。オフサイドの間は、もう1人のストライカーも得点できません。

**解除の条件:** 通り抜けた瞬間に相手陣にいた機体が全部、機体全体でハーフラインを越えて自陣へ戻ると解除されます。もう1人のストライカーも、そのとき相手陣にいたら戻る必要があります。

- その瞬間に自陣にいた機体は、戻る必要がありません。あとから前へ出ても解除の妨げになりません。
- 一度戻った機体は、また前へ出ても構いません。
- オフサイド中にもう一度通り抜けると、その瞬間に相手陣にいる機体も戻る必要があります。
- オフサイドの間は、そのチームが攻めるリングの LED が赤になります。解除すると白へ戻ります。
- オフサイドは、次のセットやペナルティキックへ持ち越しません。

## 自分のリング

(公式 8-❸)

守備では、自分のリングを正面から裏へ抜けても構いません。ただし、穴を通って正面へ戻ることはできません。リングの外を回って戻ります。

次の2つは逆侵入という反則で、ペナルティ1回です。ストライカーを含むすべての役割に当てはまります。

- 裏から穴へ少しでも入る。
- 正面から機体の半分以上入って、正面へ戻る。

機体の半分以上が自分のリングへ入ると、画面の左下に「裏へ抜けて」と出ます。そのまま裏へ抜ければ反則になりません。

## 警告とペナルティ

(公式 9-❶❷、第11章)

このゲームの警告はフライングだけです。警告が2回たまると、ペナルティ1回に変わります。警告は次のセットへ持ち越しますが、次の試合へは持ち越しません。

ペナルティが付くのは次の3つです。

- オフサイド中の得点
- 自分のリングへの逆侵入
- 警告2回

ペナルティはセットごとに数え、次のセットへは持ち越しません。

## ペナルティキック

(公式 9-❷❸❹)

セットのあとで両チームのペナルティを相殺します。回数が少ないチームが、差の回数分だけ蹴ります。回数が同じならペナルティキックはありません。

- **時間:** 差1回につき5秒です。差が2回なら、続けて10秒です。
- **出る機体:** 蹴る側のストライカー1人と、守る側のキーパーの1対1です。ほかの機体はコートから外れます。
- **蹴る人:** 番号の小さい席のストライカーです。規定の編成では1番です。
- **開始の位置:** ストライカーはハーフラインから、キーパーは試合の開始と同じ、自分のリングの下から始めます。
- **得点:** 判定はセットと同じです。時間内なら何点でも入れられますが、1点ごとにハーフラインへ戻る必要があります。
- **点数の扱い:** 入った点は、そのセットの得点に加えます。
- **反則:** ペナルティキックの最中の反則で、次のペナルティキックは起きません。

ストライカーがいないチームは1番の席が蹴ります。キーパーがいないチームは5番の席が守ります。キーパーが複数いるときは、番号の小さい席が守ります。

画面の上の得点板の左右に、今のセットの両チームのペナルティの数が出ます。ペナルティキックの知らせには、相殺した結果も出ます。

## 勝敗

(公式 10-❶❷)

**セット:** 得点の多いチームがセットを取ります。同点なら、そのセットは引き分けです。

**試合:** 先に2セット取ったチームの勝ちです。3セットが終わったら、取ったセットの多いチームの勝ちです。1勝2分でも勝ちになります。

**同点のとき:** 3セットで取ったセットの数が同じなら、延長セットを1回行います。形は通常のセットと同じです。それでも決まらなければシュートアウトを行います。

## シュートアウト

(公式 10-❸)

形はペナルティキックと同じで、1本5秒です。両チームが交互に1人ずつ蹴ります。

- 先に蹴るチームはランダムで決まります。
- 蹴る順は席の順で、1番、2番、3番です。役割は関係なく、蹴る機体の通過が得点になります。
- 守るのは相手のキーパーです。キーパーがいなければ5番の席です。
- 3人ずつ蹴り終えて、得点の多いチームの勝ちです。途中で差がついても、3人目まで蹴ります。
- 同点なら、4番、5番、1番と1人ずつ追加します。両チームが蹴って差がついた時点で決着です。
- シュートアウトの得点は、セットの得点とは別に数えます。

## 審判の合図

(公式 5-❼、6-❹)

判定はゲームが自動で行います。コートの横に主審が1人、それぞれのリングの近くに副審が1人ずつ立ち、判定を合図で見せます。画質を軽いにすると、審判の人は出ません。

| 人 | 動き | 意味 |
|---|---|---|
| 主審 | 両腕を横へ広げる | 用意、終了 |
| 主審 | 両腕を前へ伸ばす | 開始 |
| 主審 | 黄色の札を掲げる | 警告 |
| 副審 | 旗をまっすぐ上げる | 得点を認める |
| 副審 | 旗を頭の上で振る | 得点を認めない |
| 副審 | 旗を前へ伸ばしたままにする | オフサイド中。自陣へ戻る |
| 副審 | 旗を斜め下へ下ろす | 全機が戻った。オフサイド解除 |
| 副審 | チームの色の表示板を掲げる | そのチームのペナルティ |

反則と警告では、短い笛が1回鳴ります。オフサイド中の得点は、旗を振る合図だけで示します。

## 別の PC と遊ぶときに接続が切れたら

接続が切れた人の席は CPU が引き継ぎます。試合が終わるまでは、同じ席へ戻れます。部屋を作った人の接続が切れると、試合は続けられません。

## 公式ルールとの違い

| 項目 | 公式ルール | このゲーム |
|---|---|---|
| 役割 | ストライカー2人、ディフェンダー3人 | 規定は同じで、ディフェンダーをリベロ、スイーパー、キーパーにする。監督の画面で変えられ、ストライカーは2人まで |
| 機首の LED | チームの色だけ | 役割の色も光る |
| 機体の色 | 赤と青のほかは塗れる | 塗れない |
| 修理の時間 | セットの間に5分以上 | 15秒 |
| 操縦エリアの選択 | コイントスで勝ったチームが選ぶ | チームの色で決まっている |
| 墜落と交代 | 操縦できなくなった機体は棄権して、オフサイドを解除できる | 機体が墜落しないので棄権もない |
| 警告の種類 | フライングのほか、指示に従わないことなど | フライングだけ |
| セット負け、試合負け | 重い違反に適用する | ない |
| ペナルティキックの辞退 | 決勝トーナメントでは辞退できる | 必ず蹴る |
| ペナルティの得点換算 | 大会の規定で選べる | ない。換算するのは JDSF ルール |
| シュートアウトの出場者 | 各チーム3人が出て、キーパーは自由に指名できる | 席の順に蹴り、キーパーの役割の機体が守る |
| 審判 | 主審、副審、ビデオ判定 | ゲームが自動で判定する。審判の人は合図を見せるだけ |
| 警告の合図 | 決まった形はない | 主審が黄色の札を掲げる |
| 機体の型 | 認定された機体 | Class 40 の機体の形をそのまま小さくしたもの |

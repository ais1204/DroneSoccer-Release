# ドローンサッカー

ドローンサッカーの試合をパソコンで遊べるゲームです。実際の競技のルールと大きさをもとにしています。CPU との試合、同じ PC での画面分割、インターネットでの対戦ができます。

## 始め方

1. このページの緑の **Code** → **Download ZIP**、または `DroneSoccer-Windows.zip` を開いて **Download** でダウンロードします。
2. ダウンロードした ZIP を展開します。
3. 展開したフォルダの `DroneSoccer.exe` を開きます。

**「Windows によって PC が保護されました」と出たら:** **詳細情報** → **実行** を押します。個人が作ったゲームで署名がないため表示されます。

**ファイアウォールの確認が出たら:** オンライン対戦で部屋を作る人は **アクセスを許可する** を押してください。

## 必要なスペック

| | 最低 | 推奨 |
|---|---|---|
| OS | Windows 10 21H1 以降（64ビット） | Windows 11（64ビット） |
| プロセッサー | 2コア4スレッド（Intel Core i3 第8世代 / AMD Ryzen 3 クラス） | 4コア8スレッド以上（Intel Core i5 第10世代 / AMD Ryzen 5 クラス） |
| メモリー | 4 GB RAM | 8 GB RAM |
| グラフィック | Intel UHD Graphics 620 クラスの内蔵 GPU | Intel Arc の内蔵 GPU、NVIDIA GeForce GTX 1650 クラス以上 |
| DirectX | Version 11 | Version 12 |
| ネットワーク | ブロードバンド（オンライン対戦のみ） | 上り 1 Mbps 以上（10人の部屋を作るとき） |
| ストレージ | 300 MB の空き容量 | 300 MB の空き容量 |
| 追記事項 | 画質「軽い」、1280×720 | 画質「標準」、1920×1080、100 fps 以上 |

キーボード、または Xbox 形式のコントローラーで遊べます。

動きが悪いときは、タイトルの **設定** で **画質** を **軽い** にしてください。解像度、影、色の仕上げ、観客を減らして軽くします。

推奨の Intel Arc の内蔵 GPU は Core Ultra 7 155H で確かめました。1920×1080 の標準で 142 fps、軽いで 370 fps でした。それ以外の型番は、この結果からの見積もりです。

## 操作

タイトルの **操作** で配置を選べます。キーボードの割り当ては **設定** で変えられます。

| 操作 | 実機配置 | かんたん | コントローラー(実機配置) |
|---|---|---|---|
| 移動 | ↑↓←→ | WASD | 右スティック |
| 上昇・下降 | W / S | Space / Left Shift | 左スティック(上下) |
| 旋回 | A / D | Q / E | 左スティック(左右) |
| 変速(3段) | Left Shift | R | LB |
| 視点の切り替え | C | C | RB |
| メニューへ | Esc | Esc | Start |

## 遊び方

- **試合（vs CPU）:** 監督の画面で席、役割、CPU の強さ、戦術を決めて試合をします。
- **ローカル対戦:** 同じ PC で画面を分けて、最大4人で遊びます。
- **オンライン対戦:** 部屋を作ると表示される部屋コードを友達に伝えます。同じネットワークなら一覧からも入れます。
- **1人で飛ぶ:** 試合なしで自由に練習します。

オンライン対戦は、全員が同じ版のゲームを使う必要があります。新しい版が出たら全員で入れ替えてください。

接続が切れても、試合が終わるまでは同じ席に戻れます。**オンライン対戦** の **試合に戻る** を押してください。部屋を作った人が切れると試合は続けられません。

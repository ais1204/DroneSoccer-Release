# ドローンサッカー

ドローンサッカーの試合をパソコンで遊べるゲームです。実際の競技のルールと大きさをもとにしています。CPU との試合、同じ PC での画面分割、同じ Wi-Fi や LAN での対戦ができます。

## 始め方

1. `DroneSoccer-Windows-LAN.zip` を開いて **Download** でダウンロードします。
2. ダウンロードした ZIP を右クリックして **プロパティ** を開きます。**全般** の一番下にある **許可する** にチェックを入れて、**OK** を押します。**許可する** がないときは、そのまま次に進みます。
3. ZIP を展開します。
4. 展開したフォルダの `DroneSoccer.exe` を開きます。初めて開くときは 10 秒ほどかかります。

**ダブルクリックしても何も起きないときは:** 2 をしないで展開すると起きます。Windows はダウンロードしたファイルを開く前に確認の窓を出しますが、Windows 11 の 26H2 では、この窓が画面に見えないまま止まることがあります。展開したフォルダを消して、2 からやり直してください。ダウンロードフォルダに展開したときは、PowerShell で次を実行しても直ります。

```powershell
Get-ChildItem -Recurse "$env:USERPROFILE\Downloads\DroneSoccer-Windows-LAN" | Unblock-File
```

**「Windows によって PC が保護されました」と出たら:** これも 2 をしないで展開すると出ます。**詳細情報** → **実行** を押します。個人が作ったゲームで署名がないため表示されます。

**ファイアウォールの確認が出たら:** 部屋を作る人は **アクセスを許可する** を押してください。

## 必要なスペック

| | 最低 | 推奨 |
|---|---|---|
| OS | Windows 10 21H1 以降（64ビット） | Windows 11（64ビット） |
| プロセッサー | 2コア4スレッド（Intel Core i3 第8世代 / AMD Ryzen 3 クラス） | 4コア8スレッド以上（Intel Core i5 第10世代 / AMD Ryzen 5 クラス） |
| メモリー | 4 GB RAM | 8 GB RAM |
| グラフィック | Intel UHD Graphics 620 クラスの内蔵 GPU | Intel Arc の内蔵 GPU、NVIDIA GeForce GTX 1650 クラス以上 |
| DirectX | Version 11 | Version 12 |
| ネットワーク | 同じ Wi-Fi か LAN（LAN 対戦のみ） | 同じ Wi-Fi か LAN（LAN 対戦のみ） |
| ストレージ | 300 MB の空き容量 | 300 MB の空き容量 |
| 追記事項 | 画質「軽い」、1280×720 | 画質「標準」、1920×1080、100 fps 以上 |

キーボード、または Xbox 形式のコントローラーで遊べます。

動きが悪いときは、タイトルの **設定** で **画質** を **軽い** にしてください。解像度、影、色の仕上げ、観客を減らして軽くします。**画質の詳細** で、項目を1つずつ変えることもできます。

推奨の Intel Arc の内蔵 GPU は Core Ultra 7 155H で確かめました。1920×1080 の標準で 113 fps、軽いで 254 fps でした。それ以外の型番は、この結果からの見積もりです。

## 操作

タイトルの **操作** で配置を選べます。キーボードの割り当ては **設定** で変えられます。

| 操作 | 実機配置 | かんたん | コントローラー(実機配置) |
|---|---|---|---|
| 移動 | ↑↓←→ | WASD | 右スティック |
| 上昇・下降 | W / S | Space / Left Shift | 左スティック(上下) |
| 旋回 | A / D | Q / E | 左スティック(左右) |
| 変速(3段) | Left Shift | R | LB |
| 視点の切り替え | C | C | RB |
| メニュー（試合中も開ける） | Esc | Esc | Start |

## 遊び方

- **試合（vs CPU）:** クラスとルールを選び、監督の画面で席、役割、CPU の強さ、戦術を決めて試合をします。
- **ローカル対戦:** 同じ PC で画面を分けて、最大4人で遊びます。
- **LAN 対戦:** 同じ Wi-Fi や LAN の PC と遊びます。1人が部屋を作ると、ほかの人の一覧に出ます。
- **1人で飛ぶ:** 試合なしで自由に練習します。
- **CPU 観戦:** CPU だけの試合を見ます。1〜0 のキーで見る機体を変えられます。

別の PC と遊ぶときは、全員が同じ番号の版を使ってください。新しい版が出たら全員で入れ替えてください。

接続が切れても、試合が終わるまでは同じ席に戻れます。**LAN 対戦** の **試合に戻る** を押してください。部屋を作った人が切れると試合は続けられません。

## ルール

クラス（Class 40 / Class 20）とルール（FIDA / JDSF）は、試合を始める前の画面で選びます。組み合わせごとのルールブックは [RULEBOOK.md](RULEBOOK.md) から開けます。部屋の試合は、部屋を作った人の組み合わせになります。

## 更新内容

**v0.9.0**

- 試合中に設定でキーの割り当てを変えると、試合に戻っても何も操作できなくなる不具合を直しました。
- ゴールのリングを、本物と同じく吊ったものにしました。機体が当たると前後に少し揺れ、だんだん止まります。左右には揺れません。得点の判定は、揺れて動いた今のリングの位置で行います。
- とても強く当てられた機体は、1秒ほど操縦できなくなって転がりながら落ち、そのあと自分で立て直して飛び直します。当てた側は落ちません。立て直した直後の少しの間は、続けて落とされません。
- プロペラの風を計算するようにしました。ほかの機体の真下に入ると、吹き下ろしで押し下げられます。
- 通信の中身が変わったので、v0.8.1 とは同じ部屋で遊べません。全員で v0.9.0 に入れ替えてください。

**v0.8.1**

- クラスとルールを、試合を始める前の画面で選ぶようにしました。**試合（vs CPU）**、**CPU 観戦**、**ローカル対戦** と、部屋を作るときに出ます。前に選んだものが選ばれているので、同じならそのまま **次へ** で進めます。**1人で飛ぶ** はクラスだけを選びます。設定の **試合のルール** はなくしました。
- クラスとルールの説明の文が枠からはみ出さないようにしました。
- 通信の中身は変わっていないので、v0.8.0 と同じ部屋で遊べます。

**v0.8.0**

- **Class 20** を足しました。直径 20 cm の機体、4×8×3 m のコート、外径 50 cm・穴 30 cm のリングで、得点できるストライカーは2人です。
- ルールを **FIDA** と **JDSF** から選べます。JDSF では、ペナルティは1回 0.8 点としてセットの終わりに相手の得点になり（合計を四捨五入）、フライングはその場で相手に1点です。クラスとルールは、タイトルの **設定** → **試合のルール** で選びます。
- ルールブックを、クラスとルールの組み合わせごとの4冊にしました。
- 試合中と練習中に Esc / Start でメニューを開けます。試合に戻る、設定、試合をやめるを選べます。設定はその場で効きます。1台の PC の試合は、メニューの間止まります。
- 設定に **自機の目印**（表示・半透明・消す）と **垂直同期** を足しました。フレームレート上限に **画面に合わせる**、144、240 を足しました。垂直同期の規定はオフ、上限の規定は画面に合わせるです。
- **画質の詳細** で、描画の解像度、アンチエイリアス、影、色の仕上げ、観客と審判を1つずつ変えられます。
- 追従視点で自陣のリングを守るとき、カメラがリングのすぐ後ろへ寄り、リングが半透明になります。穴の LED の輪の中に自機が見えるので、穴を塞げているかが分かります。
- CPU の守り方と攻め方を、実際の試合に近づけました。守備は体当たりの勢いを抑えて外しても戻りやすくし、得点した相手が戻るのを前に立って邪魔します。数で負けたキーパーは、ゴールの前で左右に大きく振ります。ガイドは、味方のストライカーへ当たりに来る守備を先に打ち出します。当てられたストライカーは、立て直してから狙い直します。
- 試合前のサポーター席が白飛びして見えることがあったのを直しました。
- 通信の中身が変わったので、v0.7.1 とは同じ部屋で遊べません。全員で v0.8.0 に入れ替えてください。

**v0.7.1**

- 得点板の左右に、そのセットの両チームのペナルティの数を出すようにしました。
- ペナルティキックの知らせに、両チームのペナルティを相殺した結果を出します。ペナルティキックは相殺した差の分だけなので、両チームが反則したセットでは片方しか蹴りません。同じ数で相殺されたときは、ペナルティキックがないことを知らせます。
- 通信の中身が変わったので、v0.7.0 とは同じ部屋で遊べません。全員で v0.7.1 に入れ替えてください。

**v0.7.0**

- **CPU 観戦** を足しました。CPU だけの試合を、数字キーで機体ごとの視点に切り替えて見られます。
- 観客席にサポーターを置きました。大旗やタオルを振り、歌や手拍子で応援します。応援は試合の流れに合わせて変わります。**設定** で消せます。

- 試合が終わっても 60 秒は飛び続けられ、勝ったチームの喜びを見られます。時間が来るとタイトルへ戻ります。部屋の試合では部屋の画面へ戻ります。
- 得点板に、獲得したセットを出しました。
- タイトルの背景を試合の会場にしました。
- 部屋の画面に通信の遅れを出します。部屋を作った PC が Wi-Fi のときは案内が出ます。
- 16:9 以外の画面でも、表示の端が切れないようにしました。
